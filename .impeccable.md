# Design Context

## Users
Recruiters and hiring managers evaluating Andrew Wong for graduate software engineering roles. They spend seconds, not minutes, on a first pass — the job to be done is "decide fast whether this candidate is worth an interview." Secondary audience: friends/family/personal contacts via the Personal page.

## Brand Personality
Four words, all load-bearing: **precise/engineered, confident/unconventional, playful/alive, warm/human**. This is not a generic "clean SaaS portfolio" — the owner explicitly rejected that direction twice (once for looking like Claude's own cream/terracotta color scheme, once for a black/white/electric-blue minimalist pass that still read as "boring" and template-y). The bar is: distinctive enough that someone asks "how was this made?" not "which template is this?"

## Aesthetic Direction
Current direction (as of 2026-09-04): **"The Abstract"** — an academic-paper / research-preprint aesthetic. Replaced the risograph/zine direction below. Flowing two-column document layout (not a card grid): journal masthead top bar, numbered `§N` sections, figure plates with `FIG. N` plates and `doi:` style captions, margin notes, a correspondence/chronology back matter. Warm off-white paper (`#f6f4ef` light / `#131315` dark), near-black ink, a single red spot accent (`#a6291d` light / `#e2564a` dark) used sparingly (rule underlines, section numerals, live-status dots) rather than as a dual-color print system. Display type is `Source Serif 4` italic for accents alongside the existing Fraunces/serif stack; `IBM Plex Mono` / `JetBrains Mono` still carry technical/data labels (tag lines, DOI strings, stat percentages).

Still true from the prior direction: no cyan-on-dark, no purple-to-blue gradients, no glassmorphism, no soft neon glows, no forced-upright "should be italic" accent words.

Anti-references (confirmed, don't repeat): cream + burnt-orange/terracotta (too close to Claude's own branding); flat black/white/blue "exaggerated minimalism" (read as boring/template-y); the risograph/zine halftone-dot direction itself (superseded — the owner moved past it after building it out fully, see git history around 2026-08-20 through 2026-08-28).

No specific reference sites were given — direction was set by iterative rejection of prior attempts (SaaS-clean, minimalist, risograph/zine) plus the four personality words below, not by naming an app/site to copy.

## Design Principles
1. **One spot accent, used sparingly, not a flat "brand color" everywhere.** The red accent marks structure (rules, section numerals, status dots, key links) — it is not a background or a decorative fill.
2. **The document metaphor is the layout, not a skin.** Sections are numbered (`§1`, `§2`...), figures are plated (`FIG. 0`, `FIG. 1`...) with captions, not just "cards with a label added." Preserve this structure when adding content — don't fall back to a generic card grid.
3. **Precision lives in monospace labels and figure/DOI captions; warmth lives in the serif and the paper tone.** Don't blend the two — let mono carry the "engineered" data/tag reading and serif carry the human headline/body voice.
4. **Both themes (light "daybreak" / dark "eclipse") must carry the same personality**, not just inverted colors — check new work in both before calling it done.
5. **Playful means a small deliberate imperfection** (the italic accent word, a stamp-plate figure caption, a wry "Reviewer 2" margin note), not animation for its own sake or whimsical copy — the owner's actual writing voice is dry, not silly, and the UI shouldn't outpace it.
6. **Scroll-reveal entrances use a `.paper-doc.in .reveal` opacity/transform transition gated by a 40ms mount timeout (`useBentoMotion`), not IntersectionObserver.** Screenshots or visual checks taken immediately on page load can catch content mid-transition — wait ~1s (or check `prefers-reduced-motion`, which disables it) before judging a layout broken.
