# Design Context

## Users
Recruiters and hiring managers evaluating Andrew Wong for graduate software engineering roles. They spend seconds, not minutes, on a first pass — the job to be done is "decide fast whether this candidate is worth an interview." Secondary audience: friends/family/personal contacts via the Personal page.

## Brand Personality
Four words, all load-bearing: **precise/engineered, confident/unconventional, playful/alive, warm/human**. This is not a generic "clean SaaS portfolio" — the owner explicitly rejected that direction twice (once for looking like Claude's own cream/terracotta color scheme, once for a black/white/electric-blue minimalist pass that still read as "boring" and template-y). The bar is: distinctive enough that someone asks "how was this made?" not "which template is this?"

## Aesthetic Direction
Current direction (as of 2026-08-17): a **risograph/zine print aesthetic** — warm off-white paper (not cream, not stark white), near-black ink, two riso "spot colors" (red `#ef3c3c`/`#ff5b4a` and blue `#1e4b8f`/`#5b9bdb` across light/dark themes) used the way two-layer riso printing actually works, halftone dot textures, hard-edged "print misregistration" offset shadows (solid color, no blur) instead of soft glows or drop-shadows, Fraunces serif for display type (with genuine italic on accent words, not forced-upright), JetBrains Mono reserved for technical/data labels only. No cyan-on-dark, no purple-to-blue gradients, no glassmorphism, no soft neon glows — those all read as generic AI output to this user.

Anti-references (confirmed, don't repeat): cream background + burnt-orange/terracotta accent (too close to Claude's own branding); flat black/white/blue "exaggerated minimalism" (technically clean but read as boring/generic once built).

No specific reference sites were given — direction was set by explicit rejection of two prior attempts plus the four personality words above, not by naming an app/site to copy.

## Design Principles
1. **Two spot colors, not one flat accent.** The site already has a dual-accent architecture (`--accent` / `--accent-2`) — lean into it as an actual two-color print system (e.g. an offset shadow in the *other* color), not just "primary + a muted secondary."
2. **Texture and hard edges over blur and glow.** No `box-shadow`/`text-shadow` soft blurs for decoration. If something needs to pop, use a flat halftone pattern, a hard offset shadow, or a solid color block.
3. **Precision lives in monospace labels and grid textures; warmth lives in the serif and the paper tone.** Don't blend the two — let JetBrains Mono carry the "engineered" data/tag reading and Fraunces carry the "human" headline voice.
4. **Both themes (light "daybreak" / dark "eclipse") must carry the same personality**, not just inverted colors — check new work in both before calling it done.
5. **Playful means a small deliberate imperfection** (chip rotation, italic flourish, stamp-press button interaction), not animation for its own sake or whimsical copy — the owner's actual writing voice is dry, not silly, and the UI shouldn't outpace it.
